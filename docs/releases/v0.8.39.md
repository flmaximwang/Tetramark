# 0.8.39 — the stock add-form creates the stock without aliquots

`tm stock add-form` now asks for the stock itself — the kind, the entity and the kind's fields — and
writes it with zero aliquots, exactly like `tm stock add ... --aliquots 0`. Tubes move to the
separate aliquot workflow: after a successful human write the form prints a `Next:` line pointing
at `tm aliquot add-form`/`tm aliquot add`. The ordinary `tm stock add` (default one aliquot) and the
Python API are unchanged, so agents and scripts are unaffected and nothing has to migrate.

## What changed for people

- **The stock form's steps:** kind → entity → the kind's fields, in schema order. The aliquot
  count, box and slots questions are gone, and the review screen lists only those values.
- **The write:** `ledger.stocks.add(kind, entity=..., values=..., aliquots=0)`. The new stock is
  empty, its derived status is `empty`, and its row is identical to
  `tm stock add KIND --entity E --aliquots 0`; no box or slot is touched.
- **The guide line:** after a confirmed non-dry-run write in human output, line 1 stays
  `Added stock <kind> <id> with 0 aliquot(s)` and line 2 is
  `Next: add aliquots with 'tm aliquot add-form' or 'tm aliquot add <id> --count N --quantity Q --unit U'`.
  `--json`, `--dry-run`, cancel and the other forms print no such line.
- **The separate aliquot workflow:** `tm aliquot add-form`, `tm aliquot add` and
  `tm stock aliquot` add count, quantity, unit, box and slots exactly as before. `tm stock add`
  keeps its `--aliquots` default of 1 for agents and scripts.
- **Unchanged:** `tm stock add` flags and defaults, `tm stock aliquot`, `tm aliquot add`, the
  entity/box forms and `tm aliquot add-form`, the `ledger.stocks.add` signature and default, the
  schema, migrations, spec §6.2 and spec §6.4.

## Upgrade

Nothing to migrate: this is an interactive-form change only. The form calls the existing
`ledger.stocks.add(..., aliquots=0)`, so there is no schema, DDL, preset, migration, query or
dependency change, no new flag and no new editing feature. The shipped skills are re-stamped to
0.8.39.
