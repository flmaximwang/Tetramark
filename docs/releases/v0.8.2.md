# 0.8.2 — box ids in the CLI, and where a tube changes

`tm box list` now starts with the box id, and `tm box show` prints its id in the header and in JSON, so a box's uuid is visible without `--json` guesswork. `tm aliquot --help` says which command changes placement, quantity and status. Nothing breaks and nothing needs migrating.

## Box ids

- `tm box list` prints `id name kind path occupied capacity`. The table shortens `id` to a unique prefix of at least eight characters among the listed rows, the same convention as `tm stock list`; CSV and JSON keep the full uuid (JSON already carried it).
- `tm box show`'s text header is `<name>  <kind>  id: <short>  path: ...`, using the first eight uuid characters. `--json` gains `id` with the full uuid; `--format csv` keeps its slot rows (`slot,row,col,occupants`) unchanged.
- The printed short id is directly usable as a reference: `--box`/`--in` already resolve a name, full id, alias or unique id prefix, so `tm aliquot move ALQ --box <short id> --slot A1 -m ...` works without retyping the uuid.

## Aliquot help

`tm aliquot --help` now ends its description with one line: placement changes go through `move`, quantity through `use`, and status through `status`. It is the answer to the "No such command 'edit'" dead end that sent a user looking for `tm aliquot edit --set box_id=...`.

## Docs and skill references

- `skills/tetramark/references/commands.md` and `recipes.md` gain a **Move a tube to another box** recipe built on `tm aliquot move --box <name>`, and both describe the new `id` column (short in the table, full in CSV/JSON).
- `docs/spec/06-cli.md` documents the `box list` column set, the `box show` header and JSON shape, and the aliquot help line.

## Fixed after 0.8.1

- A box's uuid is readable from the human CLI views, not only from `tm box show --json`.
- The aliquot command group says where a placement, quantity or status change belongs instead of leaving the user to find a nonexistent `edit` subcommand.

## Upgrade

Nothing to migrate: CLI-only change, `spec_version` stays 6 and the ledger format is unchanged. The JSON change is additive (`box show` gains `id`).
